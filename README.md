# 🌡️ TempPredictor-ML-Skill
**Corporación Universitaria Unilasallista — Ingeniería de Software**
**Actividad:** Investigación e Implementación de Skills (Gemini)

## 📌 Introducción
Este proyecto desarrolla un **modelo de regresión lineal simple** que predice la temperatura en grados **Fahrenheit** a partir de una temperatura dada en grados **Celsius**. Se integra mediante una **Skill personalizada en Gemini** para asistir en la interpretación y análisis del modelo.

## 🎯 Objetivo
Construir un modelo `LinearRegression` que aprenda la relación matemática (`F = C × 9/5 + 32`) a partir de datos y realice predicciones precisas, automatizándolo mediante un asistente inteligente.
